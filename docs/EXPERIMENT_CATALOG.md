## Синтетические сценарии

### S1 — Полный отказ энергетики (насыщенный)

**ID:** `S1_energy_outage`  
**Источник:** Rinaldi et al. (2001) «Identifying, understanding, and analyzing critical infrastructure interdependencies», Table 1 (сценарий N1).  
**Описание:** Внезапный отказ энергетики (крупная авария, аналог Texas 2003). Шок +0.30 к нагрузке энергетики (сверх базового 0.667 → постшоковый 0.967 > C_energy=0.883).

| Параметр | Значение |
|----------|----------|
| x₀ | [0.667, 0.400, 0.333] |
| u (шок) | [0.30, 0.0, 0.0] |
| Инициатор | energy (j=0) |
| T | 50 шагов |
| K_cl | 1.0000 |
| K_q | 1.0000 |
| Δ% | 0.0% |
| H₁ статус | **насыщение** (K_cl = K_q = 1.0) |

**Интерпретация:** Шок немедленно выводит энергетику за порог C_energy. Оба детектора срабатывают на 100% прогонов. Дифференциация методов невозможна. Документируется как ограничение: большие шоки требуют более тонких показателей, чем вероятность бинарного каскада.

### S3 — Нагрузка на транспорт (маргинальный)

**ID:** `S3_transport_marginal`  
**Источник:** Rinaldi et al. (2001) аналог S3; калибровка нагрузки транспорта на уровне 0.25 (от 0.333 до 0.583).  
**Описание:** Транспортный шок (рост грузопотока, закрытие маршрутов). Транспорт остаётся ниже C_transport=0.928; каскад в энергетику стохастический (за 7 шагов x_energy достигает ~0.79–0.88 c вероятностью ~60%).

| Параметр | Значение |
|----------|----------|
| x₀ | [0.667, 0.400, 0.333] |
| u (шок) | [0.0, 0.0, 0.25] |
| Инициатор | transport (j=2) |
| T | 7 шагов (маргинальный горизонт) |
| K_cl | 0.5950 ± 0.0155 |
| K_q | 0.8830 ± 0.0102 |
| ΔK | +0.2880 |
| Δ% | **+48.4%** |
| H₁ статус | ✓ **подтверждена** |

**Интерпретация:** K_q фиксирует 88.3% прогонов с нарастанием риска ≥ 0.10 в смежных секторах, тогда как K_cl срабатывает лишь на 59.5% прогонов, когда стохастика выводит энергетику за C_energy=0.883. Разрыв +48.4% подтверждает H₁.

### S4 — Деградация водоснабжения (маргинальный)

**ID:** `S4_water_marginal`  
**Источник:** Rinaldi et al. (2001) аналог S4; шок водоснабжения +0.20 (от 0.400 до 0.600, чуть ниже C_water=0.6463).  
**Описание:** Частичный отказ системы водоснабжения (засуха, загрязнение). Количественный детектор фиксирует нарастание нагрузки на энергетику через A[energy,water]=0.350 в КАЖДОМ прогоне. Классический срабатывает лишь когда стохастика выводит x_water выше C_water.

| u (шок) | [0.0, 0.20, 0.0] |
| Инициатор | water (j=1) |
| T | 7 шагов (маргинальный горизонт) |
| K_cl | 0.6200 ± 0.0153 |
| K_q | 1.0000 ± 0.0000 |
| ΔK | +0.3800 |
| Δ% | **+61.3%** |
| H₁ статус | ✓ **подтверждена** |

**Интерпретация:** K_q=1.0 означает, что нарастание риска в смежных секторах (Δx≥0.10) детектируется в КАЖДОМ прогоне. Механизм: шок 0.20 в водоснабжение передаётся по матрице A в энергетику с коэффициентом 0.350, за 7 шагов нарастание составляет ≥0.147 >> δ=0.10 даже без стохастики.

### REAL_europe_2006 — Сбой европейской энергосети

**ID:** `REAL_europe_2006`  
**Источник:** UCTE (2006) «Final Report — System Disturbance on 4 November 2006».  
**Описание:** 4 ноября 2006 г. в 22:10 CET отключение линий UCTE ЛЭП вызвало разделение объединённой европейской энергосистемы на три острова. Шок: перегрузка ЛЭП ~+5% сверх номинала → отключения каскадом охватили 15 млн потребителей. Моделируется как малый шок энергетики (+0.05).

| Параметр | Значение |
|----------|----------|
| x₀ | [0.667, 0.400, 0.333] |
| u (шок) | [0.05, 0.0, 0.0] |
| Инициатор | energy (j=0) |
| T | 7 шагов |
| K_cl | 0.0380 ± 0.0060 |
| K_q | 1.0000 ± 0.0000 |
| ΔK | +0.9620 |
| Δ% | **+2532%** |
| H₁ статус | ✓ **подтверждена** (вырожденный K_cl) |

**Интерпретация:** Структурная особенность: малый шок энергетики не выводит транспорт или водоснабжение выше соответствующих C_j (C_transport=0.928 >> x_transport ~0.58 через 7 шагов). Это ключевой кейс: **классический оператор слеп к реальным каскадам малой интенсивности** с крупными цепочками зависимостей.

## Область применимости количественного оператора

**Превосходит классический когда:**
1. Шок недостаточен для немедленного превышения C_j (классический срабатывает лишь стохастически)
2. Но матрица A обеспечивает нарастание нагрузки в смежных секторах ≥ δ=0.10

**Эквивалентен классическому когда:**
- Большие шоки выводят систему в насыщение (оба K=1.0)

**Структурный случай:**
- REAL_europe_2006: K_cl≈0 (классический слеп), K_q=1.0 — количественный обнаруживает каскад, который классический пропускает полностью
- Причина: C_transport=0.928 слишком высок для прямого срабатывания, но нарастание через A[transport,energy]=0.500 даёт Δx=0.25 >> δ=0.10

## Этап 3 — Сравнение трёх каскадных операторов (operator comparison)

**Драйвер:** `scripts/run_operator_comparison.py`
**Артефакт:** `results/stage3_operator_comparison.json`
**Операторы:** Classical (бинарный), IIM iterative (линейный), NEVA/NLDR β=2 (нелинейный).
Реализация: `services/risk_engine/cascade_operators.py`.

**Постановка:** один унифицированный MC-прогон через `mc_harness.run_sde_once / run_iim_once /
run_neva_once` на тех же самых σ-шумах (seed-reproducible), сравнение финальных состояний.

**Цель:** выяснить, в каком спектральном режиме ($\rho$) операторы дают разные прогнозы —
базовый скрининг для выбора оператора в дальнейших этапах.

## Этап 4-ter — Рекалибровка ρ (rho recalibration)

**Диагностика:** `results/diagnostics/rho_sweep.md`
**Обоснование:** `docs/methodology/calibration_rationale.md`
**Задача:** выбрать значения $\rho_A$ (коэффициент масштабирования A при построении A*)
и $\rho_\text{rec}$ (естественного восстановления) + горизонт $T_\text{steps}$, чтобы
итеративные операторы корректно сходились в окне наблюдения.

**Итоговые значения:**

| Параметр | Значение | Обоснование |
|----------|:--------:|-------------|
| $\rho_A$ | 0.5 | Спектральный радиус A после rescale (off-diag max=0.5) |
| $\rho_\text{rec}$ | 0.3 | Скорость естественного восстановления (эмпирический выбор) |
| $T_\text{steps}$ | 50 | Достаточно для сходимости IIM/NEVA при данном $\rho$ |

## Этап 4-quint — IIM canonical vs NLDR: MAE на 4 событиях

**Драйвер:** `scripts/validation/mae_comparison.py`
**Артефакт:** `results/mae_comparison.json`
**Методология:** `docs/methodology/stage4_quint_iim_vs_nldr.md`

**Операторы:**
- IIM canonical: $q = (I - A^\star)^{-1}\,c^\star$ (закрытая форма, Haimes 2005 eq.11)
- NLDR β=2: итеративный $x_i(t+1) = \mathrm{clip}(x_i(0) + \sum A_{ij}(1 - (1-x_j)^2))$
