## 2. Интерпретация по группам

### 2.1 Сценарии с подтверждённой H₁ (Δ ≥ 25%)

**S3 (транспорт +0.25, T=7):** Транспортный шок остаётся ниже C_transport=0.928.  
Классический детектор срабатывает лишь когда стохастика выводит x_energy > C_energy=0.883 (~60% прогонов).  
Количественный — всегда, когда нарастание смежных секторов ≥ δ=0.10 (~88%).  
Δ=+48.4%: каждый третий прогон, где классический пропускает, количественный обнаруживает.

**S4 (водоснабжение +0.20, T=7):** Шок +0.20 ставит x_water=0.600 — чуть ниже C_water=0.646.  
Нарастание в энергетике: A[energy,water]=0.350 × 0.60 × 7 шагов × 0.1 = 0.147 >> δ=0.10.  
K_q=1.000 в каждом прогоне; K_cl=0.620 (стохастически).  
Δ=+61.3%.

**REAL_baltimore_2024 (транспорт +0.30, T=7):** Аналогичен S3, шок чуть больше.  
K_cl=0.606, K_q=0.884, Δ=+45.9%.

**REAL_europe_2006 (энергетика +0.05, T=7):** Малый шок энергетики.  
Классический **почти не срабатывает**: C_transport=0.928 высок, транспорт через 7 шагов достигает лишь ~0.58.  
Количественный срабатывает всегда: нарастание транспорта через A[transport,energy]=0.500 равно Δx≈0.25 >> δ=0.10.  
K_cl≈0.038 (вырожден), K_q=1.0. Δ%=+2532% — это ключевой кейс: **классический слеп к реальному каскаду**.

**REAL_india_2012 (multi-sector, T=7):** Постшоковые состояния ниже C_j.  
K_cl=0.142 (стохастика), K_q=1.000 (нарастание детерминировано). Δ=+604%.

### 2.2 Насыщенные сценарии (K_cl = K_q ≈ 1)

**S1 (энергетика +0.30, T=50):** Постшоковый x_energy=0.967 > C_energy=0.883 → немедленный каскад.  
**Texas 2021 (энергетика +0.368, T=50):** Аналогично; потеря 36.8% мощности.  
**Christchurch 2011 (multi, T=7):** Тройной шок насыщает все три сектора.

При насыщении дифференциация методов невозможна: обе метрики дают K=1.0. Это не ошибка — для катастрофических событий оба метода корректно показывают тотальный каскад. Научный интерес представляет маргинальный режим.

### 2.3 Ниже порога H₁

**S5_combined (энергетика+транспорт +0.15+0.35, T=7):** Δ%=+20.2%.  
K_cl=0.832 — уже очень высокий (предсатурация). Разрыв сужается: в предсатурированном режиме классический «догоняет» количественный. Порог 25% не достигнут, но сама тенденция верна (K_q=1.0 > K_cl=0.832).

### 2.4 Эффект α (динамическая матрица A)

Из `results/alpha_sweep.json` (N=1000, T=7):

- **S4 (вода +0.20):** mean_Δx снижается монотонно с 0.406 (α=0) до 0.357 (α=15), −12%.  
  K_cl снижается с 0.592 до 0.528 (−11%, ~4 SE — статистически значимо).  
  Механизм: φ_water<1 при x_water>C_water → ослабление A[:, water] → меньше нарастание в энергетике.

- **S3 (транспорт +0.25):** α-эффект статистически незначим.  
  x_transport=0.583 << C_transport=0.928, поэтому φ_transport=1 всегда.

**Вывод:** Деградационный механизм работает как демпфер — снижает интенсивность каскада, когда инициатор превышает порог. При малых шоках (x < C) α не активируется.

## 3. Область применимости метода

### Количественный оператор превосходит классический когда:

1. **Малый шок инициатора:** x_j + u_j < C_j → классический не срабатывает немедленно,  
   но нарастание через матрицу A даёт Δx ≥ δ в смежных секторах.

2. **Слабые связи с высоким порогом:** C_j высок (транспорт C=0.928),  
   но A-связи сильны (A[transport,energy]=0.500 → быстрый прирост).

3. **Реальный случай:** REAL_europe_2006 — K_cl≈0, K_q=1.0.  
   Классический оператор с порогом C_j **полностью слеп** к реальному каскаду.

### Классический оператор эквивалентен когда:

- Большие шоки (насыщение: оба K=1.0)
- Инициатор с низким порогом C_j близким к baseline (energy: C=0.883, baseline=0.667+u)

### Условие, при котором ни один не работает:

- Катастрофический тройной шок (Christchurch) → K_cl=K_q=1.0, оба показывают тотальный каскад,  
  но различить степень воздействия невозможно.

## 4. Сравнение с Фазой 1 (старый дискретный оператор)

Ранее использовался дискретный оператор: x_{t+1} = clip(x_t + A·x_t + u) с theta_node=0.75.  
Результаты из памяти (θ=0.75, A_wiod_v3, HTTP-сервис):
- S3: K_cl=0.331, K_q=0.368 → Δ%=+11.2% (не достигает 25%)
- S4: K_cl=0.353, K_q=0.798 → Δ%=+126%

В СДУ-модели (sde_integrator, T=7):
- S3: K_cl=0.595, K_q=0.883 → Δ%=+48.4% ✓ H₁ подтверждена
- S4: K_cl=0.620, K_q=1.000 → Δ%=+61.3% ✓ H₁ подтверждена

Различие S3: в СДУ с σ>0 стохастика повышает K_cl (0.331→0.595), что увеличивает пространство  
для разрыва K_q−K_cl. Для S4 оба метода подтверждают H₁, но разными величинами Δ%.

**Ключевое преимущество СДУ:** непрерывная траектория позволяет детально исследовать  
время первого превышения порогов и форму распределения max_delta.

## 6. Валидация на реальных авариях

**Скрипт:** `scripts/validate_real_events.py` | **Данные:** `results/validation_real_events.json`

### Метод

Входные параметры (x0, shock) — из регуляторных отчётов. Модель предсказывает деградацию секторов без знания реальных последствий. Предсказание сравнивается с документированной реальностью.

### Результаты (N=1000 MC, δ=0.10)

| Событие | Источник | K_cl | K_q | Совп. секторов | Совп. каскада |
|---------|----------|:----:|:---:|:--------------:|:-------------:|
| Baltimore 2024 | Dulin et al. 2025, Nat.Comm. | 0.625 | 0.899 | 3/3 ✓ | ✓ |
| Texas 2021 | FERC/NERC Nov 2021 | 1.000 | 1.000 | 2/3 ✗ | ✓ |
| India 2012 | CEA Aug 2012 | 0.144 | 1.000 | 3/3 ✓ | ✓ |
| UCTE 2006 | UCTE Final Report | 0.041 | 0.999 | 3/3 ✓ | ✓ |
| **ИТОГО** | | | | **11/12 (92%)** | **4/4 (100%)** |

**MAE = 0.203** (средняя абсолютная ошибка по амплитуде деградации).

### Ключевые находки

**UCTE 2006 — доказательный кейс:**  
Малый шок энергетики (+0.05) → K_cl=0.041 (классический практически слеп).  
K_q=0.999 (количественный обнаруживает в каждом прогоне).  
Реальность: каскад транспортной инфраструктуры произошёл (подтверждено регулятором).  
**Вывод: количественный метод прав, бинарный метод ошибается.**

**Texas 2021 — единственный промах (1/12):**  
Модель не предсказывает деградацию водоснабжения: A[water,energy]=0.006 в WIOD Leontief (экономические потоки) не отражает физическую зависимость водяных насосов от электросети. Это ограничение метода калибровки: WIOD фиксирует денежные транзакции, не физические инфраструктурные зависимости.

### Фраза для защиты

> «Параметры шока — из отчётов FERC, CEA, UCTE и Nature Communications. 
> Модель получает только силу удара. Она не знает, какие секторы 
> деградировали и на сколько. Но предсказывает каскадную картину, 
> совпадающую с документированной реальностью в 11 из 12 секторных пар (92%).
> Единственный промах — водоснабжение в Texas 2021 — является известным 
> ограничением WIOD-калибровки: экономические коэффициенты Леонтьева 
> не отражают физическую зависимость водяных насосов от электросети.»

## 7. Этап 4-quint: MAE — IIM canonical vs NLDR (β=2)

**Скрипт:** `scripts/validation/mae_comparison.py` | **Данные:** `results/mae_comparison.json`
**Методология:** `docs/methodology/stage4_quint_iim_vs_nldr.md`

### Постановка

Сравнение качества прогноза интенсивности деградации секторов двумя детерминированными
операторами: каноническим IIM (закрытая форма $q = (I - A^\star)^{-1}\,c^\star$,
Haimes 2005 eq.11) и NEVA/NLDR ($\beta=2$, итеративный, Barucca et al. 2020).

Ground truth — иерархия: первичная (регуляторные отчёты через `cascade_events.yaml`) →
вторичная (`results/validation_real_events.json::reality.delta_approx`).

### Результаты

| Событие | Ground truth источник | MAE IIM canonical | MAE NLDR β=2 |
|---------|----------------------|:-----------------:|:-----------:|
| EUROPE_2006 | UCTE (secondary) | **0.0515** | 0.1200 |
| TEXAS_2021 | FERC/NERC + YAML primary (water, transport) | **0.3558** | 0.5899 |
| INDIA_2012 | CEA Aug 2012 (secondary) | **0.1828** | 0.2622 |
| BALTIMORE_2024 | Dulin et al. Nat. Comm. 2025 | 0.1205 | **0.0950** |
| **Среднее (out-of-sample)** | | **0.1777** | 0.2668 |

На 3 из 4 событий IIM точнее; на BALTIMORE_2024 NLDR лучше (инициатор — транспорт,
невысокий шок, где нелинейность NLDR ближе к реальности).

$\Delta = -50.2\%$ — **IIM canonical точнее NLDR на 50%**.

### H₁: NOT_CONFIRMED

Исходная гипотеза (NLDR ≥25% точнее IIM за счёт нелинейного насыщения) **не подтверждена**.
Обратный эффект: при $\rho(A^\star) = 0.3955 \ll 1$ линейная модель IIM даёт консистентно
умеренные прогнозы, тогда как насыщающая нелинейность NLDR $g_\beta(x) = 1 - (1-x)^\beta$
с $\beta=2$ **переоценивает** деградацию сильносвязанных секторов (транспорт).

**Интерпретация:** нелинейные операторы (NEVA, DebtRank-non-linear) оправданы только в
режиме высокой связности ($\rho$ близко к 1), где каскад насыщает систему. Для текущей
WIOD-калибровки $\rho(A^\star) < 0.4$ — режим затухания, где линейные модели доминируют.

**Честный фундаментальный вывод:** выбор оператора должен следовать из спектрального режима
системы, а не постулироваться априори.
